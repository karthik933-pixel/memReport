# memReport
memReport is a desktop system monitoring application that tracks running processes, memory and CPU usage through an interactive dashboard. It features an LLM-powered assistant that lets users ask natural-language questions about system resource usage, application activity and identify unused applications.

## Dashboard Modules

- **Overview**: Real-time system health summary, rolling 60s CPU activity graph, and drive gauges.
- **CPU & Cores**: Global utilization and per-core workload breakdown across logical processors.
- **Memory (RAM)**: Physical RAM allocation, cached standby, committed metrics, and DDR5 hardware specs.
- **Storage**: Multi-drive monitoring for drives `C:\`, `D:\`, and `E:\` with discovery of large files and targeted cleanup suggestions.
- **Process Manager**: Filterable, searchable active task governor with CPU & RAM utilization tracking.
- **Idle Apps Finder**: Identifies inactive background applications with high memory footprints and provides hibernation options.
- **Ask AI**: Natural-language telemetry assistant powered by LLM integration.
